# {{PROJECT_NAME}}

Starter template for a SphereKit app using React with the small native JSX
surface from `@spherekit/react`.

The app follows a Tauri-like split between the web renderer and native app
backend:

```text
src/
├── renderer/  # TypeScript + React UI
└── app/       # Rust backend + Cargo
```

```tsx
<View>
  <Text>Hello</Text>
  <Button title="Play" />
  <Slider value={0.65} />
</View>
```

The renderer sends committed React snapshots and receives native events through
the JSON Lines API Bridge. The Rust backend stores them in `ReactHost` and can
lower the tree into SphereKit native UI elements.

The project is generated by `spherekit react` and is designed to build on
Windows, macOS, and Linux. The JSON Lines API Bridge is transport-neutral: a
WebView, FFI callback, child process, or socket can provide the transport.

CSS is shared by both sides. Install it from native code with
`AppBackend::set_stylesheet`, or from React with
`await bridge.setStylesheet(css)`, then use `className`, `id`, and inline
`style` props on native components.

Install dependencies and compile both sides with:

```bash
bun install
spherekit build --release
```

To target another machine, pass a platform or Rust target triple:

```bash
spherekit build --target windows
spherekit build --target aarch64-apple-darwin
```
